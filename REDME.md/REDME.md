# Aplicativo Pinterest 
Pinterest Alfinete + Interesse = Mural de inspirações

 O Pinterest é uma plataforma de descoberta visual para encontrar ideias como receitas.

 Serve como um conjunto conceitual, como um mural digital. O aplicativo possibilita a organização e salvamento de planejamentos criativos que se encaixa de acordo com as preferências do usuário.

 Deve ser utilizado em momentos de inspiração visual, planejamento de projetos, criação de conteúdo, acompanhamento de tendências, entre outros.

## Publico Alvo
O público-alvo é majoritariamente feminino, representando cerca de 70% dos usuários. A maior parte tem entre 18 e 34 anos, com destaque para a Geração Z e os Millennials.

## Principais Recursos e Funcionalidades: 

```text
/
Pins: Imagens ou vídeos que mostram ideias, tutoriais, produtos ou receitas.

Pastas: Locais para salvar, organizar e categorizar os Pins, com opção de criar subseções por temas.

Pesquisa por Imagem: Ferramenta que usa a câmera do celular para identificar objetos e encontrar produtos ou fotos semelhantes.

Extensão de Navegador: Plugin que permite salvar conteúdos diretamente de qualquer site para as pastas do Pinterest.

Mensagens Diretas: Recurso para enviar Pins e conversar sobre eles com amigos ou grupos.

Conta Business: Perfil voltado para empresas criarem anúncios e divulgarem produtos ou serviços com foco em tráfego para sites.
```

## Tecnologias ultiluzadas no aplicativo
O Pinterest começou como uma pequena empresa e cresceu para uma empresa que serve mais de 178 bilhões de Pins para mais de 250 milhões de pessoas.
Assim, tornou-se imprescindível o desenvolvimento de tecnologias que visam maior velocidade e alta escala, mantendo a simplicidade, para comportar a gigante circulação de dados para milhões de usuários.
Veremos a seguir quais tecnologias são essas:
Machine Learning: modelo de IA para personalização de recomendações de Pins e anúncios;

Content Distribution: sistema para encontrar e entregar Pins rapidamente em grande escala;

Data Management: organização, qualidade, governança e descoberta dos dados;

Experimentation: infraestrutura para testar novas tecnologias e medir resultados;

Cloud: infraestrutura em nuvem para manter o Pinterest rápido, disponível e escalável;

Supported Languages: uso e manutenção de linguagens como Java, Python, JavaScript, C++ e Go;

Core Client Platform: tecnologias dos aplicativos/clientes para oferecer uma experiência rápida e adaptável;

API: sistema de APIs que conecta os clientes do Pinterest aos serviços internos e externos.

## Requisitos técnicos 
- Front-end: React + CSS
- Back-end: Node.js + Express
- Banco de dados: PostgreSQL
- Autenticação: JWT
- Armazenamento de imagens: Cloudinary
- API: REST
- Responsivo para celular e computador.
- Upload, criação e exclusão de pins.
- Criação de boards para organizar pins.
- Sistema de login e cadastro.
- Busca por pins e usuários.
